# Cumulus Lab — Creating an SSH-Accessible Server on LNU's OpenStack Cloud

Cumulus is Linnaeus University's (LNU) OpenStack-based private cloud (IaaS), accessible at [cumulus.lnu.se](https://cumulus.lnu.se) via web UI, API, the `openstack` CLI, or Infrastructure-as-Code tools. Anything that runs Ubuntu can run on it.

## What This Repo Covers

This repo documents the full walkthrough for creating an SSH-accessible server on Cumulus, based on the LNU course slides (source: a 13-slide "Cumulus" lab presentation). It also documents real troubleshooting encountered while actually doing the lab on Windows — a gap the official slides don't cover.

The goal is to give classmates a working reference that gets them from zero to a running, SSH-accessible Ubuntu server without hitting the same walls.

## Steps Overview

1. Create an SSH keypair
2. Create a network, router, and subnet
3. Create the server
4. Open a security group for SSH
5. Attach a floating IP
6. Connect over SSH

See [docs/commands.md](docs/commands.md) for the full working command reference.

## Prerequisites

- The `openstack` CLI, installed via:
  ```bash
  pip install python-openstackclient
  ```
- An RC file or `clouds.yaml` downloaded from the Cumulus dashboard (Project → API Access → Download OpenStack RC File)

## Environment Note

This lab was done on Windows using Git Bash (MINGW64), not PowerShell or WSL. This matters: one of the documented bugs is Windows-specific — a CRLF line-ending corruption issue with SSH private keys generated by the `openstack` CLI. See [docs/troubleshooting.md](docs/troubleshooting.md#3-ssh-key-fails-with-error-in-libcrypto-unsupported-windows-specific) for details.
